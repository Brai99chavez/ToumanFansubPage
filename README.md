# ToumanFansub

Sitio de ToumanFansub, un grupo de fans que traducía al español el manga Tokyo Revengers.

## Qué es

Un proyecto de práctica de 2021: la página del grupo, para leer los capítulos online y sumarse a sus redes.

## Qué tiene

- Portada con la sinopsis del manga y un botón para unirse al Discord.
- Grilla de capítulos (del 141 al 173), cada uno en su página, con botones para volver al inicio y pasar al siguiente.
- Redes sociales (Twitter e Instagram) y accesos directos a Discord, Facebook y donaciones.

## Tecnologías

HTML y CSS, sin frameworks.

## Cómo correrlo

Necesitás Node.js (solo para el servidor local).

```bash
git clone https://github.com/Brai99chavez/ToumanFansubPage.git
cd ToumanFansubPage
npx serve
```

Abrí la dirección que muestra la terminal. También se puede abrir `index.html` directo, pero el botón de volver al inicio necesita el servidor.
